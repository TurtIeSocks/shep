VERIFICATION

Verification is intended to assist the Chocolatey moderators and community in
verifying that this package's contents are trustworthy.

This package downloads its binaries at install time rather than embedding
them. They come from the shep project's own GitHub release, which is the
official distribution point:

  https://github.com/shep-pm/shep/releases

The archive is shep-x86_64-pc-windows-msvc.zip, and the SHA256 checked at
install time is the one in chocolateyinstall.ps1. To verify it yourself,
download the same archive and compare:

  Get-FileHash shep-x86_64-pc-windows-msvc.zip -Algorithm SHA256

The same value is published beside the archive on the release as
shep-x86_64-pc-windows-msvc.sha256, and again in that release's SHA256SUMS.
The sidecar drops the archive's extension rather than appending to it, so
there is no shep-x86_64-pc-windows-msvc.zip.sha256 to fetch.

The binaries are built from tagged source by
.github/workflows/release-artifacts.yml, which also records Sigstore build
provenance for each archive. That attestation can be checked with:

  gh attestation verify shep-x86_64-pc-windows-msvc.zip --repo shep-pm/shep
